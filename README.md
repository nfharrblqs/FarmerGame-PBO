# Tiny Farmer 🌱🌟

Simple pixel-art farming game built with Python!

---------------------------------------------------------------------------------------------------


## ✨ Features
- 🌱 Plant and harvest crops
- 💰 Sell crops and animal products for gold
- 🏪 Visit shops to buy seeds and animals
- 📦 Manage your inventory
- 🛌 Sleep to restore energy
- 🐄 Raise animals and collect their products

---------------------------------------------------------------------------------------------------

## 🎮 Gameplay

### How to Play

1. Buy seeds
2. Plant crops
3. Water crops
4. Harvest crops
5. Sell crops
6. Buy animals
7. Feed Animals
8. Harvest animal product 
9. Earn more money

---------------------------------------------------------------------------------------------------

## 🛠️ Technologies Used

- Python Programming Language
- Object-Oriented Programming (OOP)
- Pixel Art Assets
